STANDARD CALCULATOR

1. Extract this ZIP file.
2. Keep index.html, style.css and script.js in the same folder.
3. Open index.html in Chrome, Edge, Firefox or another modern browser.

No installation, internet connection or external libraries are needed.

index.html: page structure and buttons.
style.css: colours, layout, responsiveness and button styling.
script.js: calculations, memory, keyboard input and history.

Keyboard: numbers, decimal point, +, -, *, /, %, Enter or =.
Escape clears everything; Delete clears the current entry; Backspace deletes a digit.

The calculator starts at 0. Enter 23 + 6 = to reproduce the reference example.
Operations run left to right, like a standard desktop calculator.
For addition/subtraction, percentages are relative to the first operand.
Memory and history last for the current page session.
The title-bar controls minimize, resize and hide the calculator card.
They do not control the actual browser window.
